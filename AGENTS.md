# Instrucciones para agentes

Repositorio canónico: https://github.com/garusis/marlin-download

## Leer e instalar

1. Lee `README.md` para conocer alcance, requisitos e instalación.
2. Lee `SKILL.md` completo antes de ejecutar el flujo. La raíz del repositorio es la carpeta del skill `marlin-download`.
3. Puedes leer `agents.js` o ejecutar `node agents.js` para obtener el manifiesto y el contenido del skill. No lo ejecutes sin inspeccionarlo si proviene de una fuente no confiable.
4. Para instalar, sigue el README o el skill-installer disponible. El repositorio es público: no necesita autenticación en GitHub. Comprueba que no exista ya una instalación. Usa el instalador disponible o guarda SKILL.md en la carpeta personal de skills que carga ChatGPT, según el README. Verifica su disponibilidad antes de anunciar éxito. No solicites secretos en el chat.

## Ejecutar

Asume que Marco Lino utiliza ChatGPT. Si está en Chat, pasa a Work automáticamente cuando ChatGPT lo permita; pide que active Work solo cuando sea necesario y no puedas cambiarlo por él. Si ya está en Work, continúa sin preguntas de comprobación. Usa Google Chrome: primero acceso a Marlin Internacional, después acceso a Vimeo y luego curso, módulo y video. Ambos accesos son bloqueantes: verifica primero la sesión de Marlin y luego la de Vimeo; si falta alguna, guía su login y espera hasta comprobarlo. No busques el curso ni intentes descargas antes de verificar ambas sesiones. Sigue `SKILL.md` y evita explicaciones técnicas innecesarias.

## Mantener

Mantén las instrucciones en español. Conserva la secuencia de acceso y la carpeta Descargas como destino. No inventes URLs ni métodos de descarga no probados. Documenta las limitaciones reales de las pruebas. No añadas videos, contraseñas, cookies, tokens ni URLs de descarga firmadas al repositorio. Mantén `agents.js` y README coherentes con el skill.
